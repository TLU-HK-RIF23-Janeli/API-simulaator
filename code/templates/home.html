TI API simulaator

Universaalne tehisintellektipõhine REST API mock server

See simulaator loob TI abil realistlikke andmeid iga võimaliku ressursi jaoks. Esimene päring genereerib andmed, järgmised päringud tulevad andmebaasist, mis tagab stabiilse struktuuri. Lisaks on kasutajal võimalus päringuparameetriga kirjeldada soovitud andmestruktuuri.

Märkus: see tööriist töötab inglise keeles, seega API kirjeldus ja päringud peaksid olema inglise keeles, et TI saaks õigesti genereerida andmeid.

Kuidas see töötab?

1. API kirjeldus

Esmalt tuleb määrata API kirjeldus, mis defineerib, mis API-t rakendus simuleerib.

Kuidas?

Saada POST päring lõpp-punktile /specification:

{"specification":"API description"}

2. TI andmete generatsioon

Esimesel päringul loob tehisintellekti mudel (OpenAI GPT 4o-mini) realistlikud andmed vastavalt API kirjeldusele, päringule ning soovitud andmestruktuurile, juhul kui see on päringuparameetrites kirjas.

Märkus

Ressursside soovitud väljad on mõistlik kohe koodis defineerida, et vältida andmete struktuuri muutusi.

3. Stabiilne andmebaas

Andmed salvestatakse SQLite andmebaasi. Järgmised päringud samale lõpp-punktile tagastavad eelnevalt genereeritud andmeid.

4. Andmeskeemi kontroll

?schema= parameeter võimaldab tehisintellektile edastada täpse väljade nimekirja, mis ressursil olema peaks. Nii on võimalik tagada andmestruktuuri stabiilsus ka tühja andmebaasi puhul.

Peamised võimalused

Toetatud HTTP meetodid

  • GET — andmete lugemine (kogu kollektsioon või üks element)
  • POST — uue ressursi loomine
  • PATCH — olemasoleva ressursi muutmine
  • DELETE — ressursi kustutamine (eemaldatakse andmebaasist ning lisatakse musta nimekirja)

Päringuparameetrid

  • ?limit=10 — tagastab täpselt määratud arvu kirjeid
  • ?schema=title,deadline,status — sunnib AI-d kasutama täpselt neid välju
  • ?<any_other_param>=value — dünaamilised päringuparameetrid andmete sorteerimiseks ja filtreerimiseks
