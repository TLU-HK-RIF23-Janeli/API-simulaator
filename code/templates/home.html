AI API Simulator

Universaalne AI-põhine REST API mock server

See simulaator loob AI abil realistlikke andmeid iga võimaliku ressursi jaoks. Esimene päring genereerib andmed, järgmised päringud tulevad andmebaasist, mis tagab stabiilse struktuuri. Lisaks on kasutajal võimalus päringuparameetriga kirjeldada soovitud andmestruktuuri.

Kuidas see töötab?

1. API kirjeldus

Esmalt tuleb määrata API kirjeldus, mis defineerib, mis API-t rakendus simuleerib.

2. AI-generatsioon

Esimesel päringul loob tehisintellekti mudel (OpenAI GPT 4o-mini) realistlikud andmed vastavalt API kirjeldusele, päringule ning soovitud andmestruktuurile, juhul kui see on päringuparameetrites kirjas.

3. Stabiilne andmebaas

Andmed salvestatakse SQLite andmebaasi. Järgmised päringud samale lõpp-punktile tagastavad eelnevalt genereeritud andmeid.

4. Andmeskeemi kontroll

?schema= parameeter võimaldab tehisintellektile edastada täpse väljade nimekirja, mis ressursil olema peaks.

Peamised võimalused

Toetatud HTTP meetodid

  • GET — andmete lugemine (kogu kollektsioon või üks element)
  • POST — uue ressursi loomine
  • PATCH — olemasoleva ressursi muutmine
  • DELETE — ressursi kustutamine (eemaldatakse andmebaasist ning lisatakse musta nimekirja)

Päringuparameetrid

  • ?limit=10 — tagastab täpselt määratud arvu kirjeid
  • ?schema=title,deadline,status — sunnib AI-d kasutama täpselt neid välju
